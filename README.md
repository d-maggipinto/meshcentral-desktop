# MeshCentral Desktop 2.22.1 (archived build)

This is an **archived release** of MeshCentral Desktop, an unofficial native Linux desktop client
for MeshCentral by Denis Maggipinto, CYVELION LTD. It was made before the project was published and
was rebuilt for publication on 2026-09-30:

- personal and company data from the original build was replaced (package maintainer, homepage,
  application id, example server address),
- on-screen texts and comments were reworded without long dashes,
- the license files were added.

The application behaves like the original 2.22.1. It is kept for reference only: please use the
latest release from https://github.com/d-maggipinto/meshcentral-desktop/releases.

Contents: `pkg/` is the Debian package tree (`fakeroot dpkg-deb --build --root-owner-group pkg`
builds the `.deb`).
